# UpflexSolutions 🌿

> Turning discarded plastic banners into livelihoods, one stitch at a time.

**UpflexSolutions** is a circular economy social enterprise tackling plastic 
waste and economic disparity by upcycling discarded PVC banner waste into 
durable, market-ready consumer goods — while training and empowering local 
female artisans.

This repository contains the official marketing/informational website for 
UpflexSolutions, built to showcase our mission, hub activities, impact 
metrics, and the team behind the initiative.

*A project initiative of Global Shaper Peshawar Hub.*

## 🛠️ Built With

- ⚡ **Next.js** (App Router)
- 🎨 **Tailwind CSS**
- 🎬 **Framer Motion** — scroll & interaction animations
- ▲ **Vercel** — deployment

## ✨ Features

- Fully responsive, mobile-first design
- Smooth scroll-triggered animations
- Animated impact counters
- SEO-optimized (Next.js Metadata API, Open Graph tags)
- Team & activity showcase sections
